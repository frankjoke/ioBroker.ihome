# Fluent gate icons

`fluent_gate_opened.png` and `fluent_gate_closed.png` come from
[Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons)
(MIT License). They were copied out of the iqontrol bundle so iHome keeps them
after iqontrol is removed.

Served by the web adapter at `/ihome/icons/fluent/…`; use them through the
icon picker's **URL/SVG** tab, e.g.
`/ihome/icons/fluent/fluent_gate_opened.png`.
