<objective>
Make the adapter's legacy-copy / placeholder logic reachable by a unit test without re-implementing the adapter:
move the decision out of `main.js` into a pure CommonJS helper that both the adapter and a Vitest test load, then
prove it.

Purpose: PERSIST-04 names the highest-consequence decision the adapter makes — whether the `config.*` value is
"empty" and therefore replaceable. Getting it wrong overwrites the operator's document; getting it too
conservatively means the real document never comes across. Today that decision is only reachable inside
`main.js`, which no unit test can load (a js-controller is required to `require` it — measured: exit code 10,
"Cannot find js-controller").
Output: `lib/adapter-migrate.js`, `src/lib/config/adapter-migrate.test.ts`, the rewired `main.js`, and the
`lib/` entry in `package.json` `files`.

**Probe-fallback accounting (spec-less phase).** The edge probe's one PERSIST-04 row (unclassified, unresolved) is
carried verbatim in `must_haves.assumptions` above. The prohibition recall's phase-level list has 5 items; this
plan carries the two data-preservation ones (the other three live in 01-01, 01-03 and 01-04).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| broker states → adapter | `config.<name>`, the legacy `0_userdata.0.Test.AiHome.<name>` states and the old root states are read as untrusted values; the adapter's decision over them can destroy the operator's document or their only backup. |
| repo → published tarball | `package.json` `files` decides what a real broker receives; a missing entry is invisible to every local test. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Tampering | `isPlaceholder` misjudging a real document as empty | high | mitigate | The tile-bearing case is asserted explicitly in Task 1's tests, and the same function is the only thing standing between a misjudged read and a destroyed document. |
| T-01-06 | Tampering | `mayDropRootState` deleting the last copy | high | mitigate | The keep-condition (config empty while the root carries a value) is a named test, and the legacy namespace is never a deletion target in any branch. |
| T-01-07 | Denial of Service | the helper missing from the published tarball | medium | mitigate | Task 3 adds the `files` entry and gates it with `npm pack --dry-run`, because no local test can observe it. |
| T-01-SC | Tampering | npm/pip/cargo installs | low | accept | No packages are installed in this plan; the helper uses only Node built-ins and the existing `@iobroker/adapter-core`. Any new install would need the package-legitimacy gate plus a blocking human checkpoint. |
</threat_model>
